Linear Regression model workflow

  1. Load the Global Water Consumption CSV using Pandas.
  2. Clean missing values, duplicates and inconsistent records.
  3. Encode categorical fields and select numerical features.
  4. Split the data into 80% training and 20% testing sets.
  5. Train Linear Regression and predict test-set demand.
  6. Evaluate predictions using R², MAE and RMSE.
The PPT describes the model plan. The metric values shown here are sample placeholders until a model is trained on the dataset.

Project presentation

Intelligent Agent-Based Water Demand Forecasting and Optimization System using Linear Regression

CSA1713 – Artificial Intelligence

Presented by: Priya Varshini. T, Bhuvaneswari. T, Marsha Melish, Yogasri Senthilkumar

Guided by: Dr. Sundar Rajan S

Project objectives

  • Forecast water demand at country and district level from 2025 onward.
  • Evaluate the model using R², MAE and RMSE.
  • Monitor forecasts and raise alerts for high demand and water scarcity.
  • Optimize allocation and present results through charts and tables.

Proposed system architecture

Kaggle CSV → Preprocessing → Linear Regression → Forecast → Agents → Optimization → Dashboard

Existing system vs proposed system

Existing systemProposed system
Manual calculations and rough averagesLinear Regression forecasting from historical records
Manual data analysisAutomated demand prediction
Fixed schedules or human-only decisionsOptimization-supported allocation

The proposed application combines Linear Regression forecasting, intelligent agent monitoring and water allocation optimization. Forecast charts and alerts can help planners understand future demand, identify potential shortages and make more informed decisions to reduce wastage and support sustainable water use.
